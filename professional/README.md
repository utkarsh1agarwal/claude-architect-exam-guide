## The one idea to remember

> Name the **binding constraint**, then pick the option that **enforces** (permissions, hooks, tool surface, code) rather than instructs, **prevents** rather than detects when harm is irreversible, fixes the **stage that actually failed**, and is **honest about its trade-off**.
